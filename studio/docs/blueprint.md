# **App Name**: RailSight MVP

## Core Features:

- Admin UI: Implement Admin View with User Management and Cable Plan Upload pages.
- Supervisor UI: Implement Supervisor View with a Verification Queue displaying asset details, submitted photos, and action buttons.
- Officer UI: Implement Officer View with a Compliance Dashboard showing Section Compliance Status and a Cable GIS Map with filtering.
- Layout & Navigation: Develop a fixed navigation sidebar, a header displaying user information, and a logout button.
- Tech Stack: Use ReactJS, JavaScript, and Tailwind CSS for frontend development, ensuring no TypeScript is used.

## Style Guidelines:

- Primary Blue (#000080) for the main navigation bar, primary buttons, and links.
- Action Red (#D32F2F) for critical alerts, overdue tasks, error messages, and reject/delete buttons.
- Warning Orange/Yellow (#FFA000) for items pending verification or requiring attention.
- White (#FFFFFF) for the main background of content areas.
- Black/Dark Gray (#212121) for all primary text to maximize readability.
- Font: 'Arial', sans-serif, for all text elements. Font sizes must be large and clear.
- Use bold text to highlight key information like asset names and status.
- Fixed navigation sidebar on the left for easy access to all sections.
